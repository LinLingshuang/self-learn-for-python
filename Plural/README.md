# Mandelbrot 绘制示例

此项目包含一个简单的 Python 脚本 `mandelbrot.py`，用于生成并显示/保存经典曼德勃罗集合。

快速开始：

```bash
pip install -r requirements.txt
python mandelbrot.py --width 1200 --height 800 --max-iter 500 --output mandelbrot.png
```

不想保存文件可以直接运行：

```bash
python mandelbrot.py
```

脚本支持调整坐标范围、分辨率和迭代次数，详见 `python mandelbrot.py --help`。
